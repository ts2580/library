# Bookshelf 3.2.0

지점 재고 금액 그래프 복원, 책 상세·직접 추가 화면 개선 및 알라딘 상품 링크 보강.

## 변경 내용

- 지점별 재고 금액 그래프 복원 및 그래프에서 지점 상세로 이동하는 동선 제공. 한글·공백·퍼센트 문자가 포함된 지점 식별자의 구분과 이동 유지.
- 책 상세 출간일을 시간·시간대 변환 없이 연월일로 표시.
- QHD 이상 화면의 직접 추가 미리보기에서 긴 제목·저자·설명이 카드 밖으로 넘치는 문제 수정.
- 책 상세 권 목록에 `알라딘에서 추가` 링크 배치 및 현재 책을 대상으로 한 제목 검색 유지.
- `저자/설명 알라딘에서 넣기` 실행 시 각 권의 빈 상품 링크도 함께 보강. 저자·설명이 이미 있는 권도 링크가 비어 있으면 조회하며 기존 값 보존.
- ISBN이 있는 권은 일치하는 판본의 HTTP/HTTPS 상품 링크만 저장. 하이픈·공백·ISBN10 소문자 `x`를 정규화해 비교하고 제목 검색에서 찾지 못하면 ISBN 키워드 검색 수행.
- 저장 트랜잭션에서 현재 ISBN과 링크를 다시 확인하여 조회 중 ISBN 변경으로 인한 이전 판본 링크 저장과 직접 입력 링크 덮어쓰기 방지.
- 탭·줄바꿈·유니코드 공백만 있는 링크도 빈 값으로 판정하여 보강.

## 기존 3.0.0·3.1.0 설치 업데이트

기존 `.env`와 실제 데이터 볼륨 이름을 유지하고 웹·워커를 같은 버전으로 함께 교체합니다.

```sh
BOOKSHELF_IMAGE=trstyq/bookshelf:3.2.0 docker compose -f docker-compose.release.yml pull
BOOKSHELF_IMAGE=trstyq/bookshelf:3.2.0 docker compose -f docker-compose.release.yml up -d
```

기존 DB 버전 4를 사용하며 새 스키마 마이그레이션은 없습니다. 이미 등록된 ISBN과 기존 저자·설명·상품 링크는 그대로 유지합니다. 빈 상품 링크는 해당 책 상세에서 정보 보강 버튼을 눌러 채웁니다.

기본 external volume은 `Bookshelf-next`와 `Bookshelf`입니다. 실제 이름이 다르면 `BOOKSHELF_DATA_VOLUME`·`BOOKSHELF_LEGACY_VOLUME`을 지정하며 기존 `BOOKSHELF_NEXT_VOLUME`도 사용할 수 있습니다. 새 빈 볼륨으로 바꾸지 않고 기존 DB·표지·백업을 함께 유지합니다.

Java 데이터 이전이 필요하면 [이전·전환 절차](ONE_CLICK_MIGRATION.md)의 ca2 이전용 이미지로 먼저 이전합니다.
