# Bookshelf 3.3.0

재고 갱신 취소 및 오류·진행 상태 복구 개선.

## 변경 내용

- 현재 계정의 대기·진행 작업을 중단하는 **갱신 취소** 버튼 추가. 취소 전까지 저장된 재고와 집계 유지 및 새 갱신 시작 지원.
- 취소한 작업의 늦은 조회 결과 저장 차단. 이전 작업의 취소 요청이 새 작업이나 다른 계정의 작업을 중단하지 않도록 보호.
- 갱신 시작·취소·전체 삭제 요청에 15초 제한 및 오류 코드 팝업 적용. 응답을 잃었을 때 서버 상태 재조회로 진행 표시 복구.
- 작업 실패뿐 아니라 일부 도서 조회 실패도 팝업으로 안내. 대기 1분·진행 상태 정체 2분 경과 시 지연 팝업 및 취소 안내 표시.
- 요청 응답 유실 후 처음 조회한 결과가 이미 완료·삭제 상태여도 재고 목록·건수·금액·지점 차트 갱신.
- 작업 획득을 단일 SQL로 처리하여 취소와 경합할 때 워커가 종료되는 문제 수정. 책 상세의 취소 상태 처리 및 모바일 버튼 배치 보완.

## 기존 설치 업데이트

`3.3.0` 이미지 발행을 확인한 뒤 기존 `.env`와 실제 데이터 볼륨 이름을 유지하여 웹·워커를 함께 교체합니다.

```sh
BOOKSHELF_IMAGE=trstyq/bookshelf:3.3.0 docker compose -f docker-compose.release.yml pull
BOOKSHELF_IMAGE=trstyq/bookshelf:3.3.0 docker compose -f docker-compose.release.yml up -d
```

DB 스키마 버전 4를 유지하며 새 마이그레이션은 없습니다. DB·표지·업로드·백업은 기존 볼륨을 그대로 사용합니다.

일괄 갱신은 워커가 작업을 시작할 때 현재 계정의 이전 재고를 삭제하고 새 결과를 저장합니다. 대기 중에는 기존 재고를 유지하며 다른 계정 재고는 삭제하지 않습니다. 진행 중 취소 시 취소 시점까지 저장된 결과를 유지합니다. 이미 진행 중인 외부 요청은 반환될 수 있으며, 취소 이후 결과 저장 및 후속 도서 조회는 중단합니다.
