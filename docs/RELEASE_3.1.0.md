# Bookshelf 3.1.0

책 상세 편집과 모바일 알라딘 등록 동선 개선 및 설명 원문 보존 수정.

## 변경 내용

- 책 상세 설명 입력란의 전체 너비 사용 및 책 삭제·알라딘 정보 보강·저장 버튼 배치 개선.
- 600px 이하 화면의 알라딘 검색 결과 상단에 추가 버튼 제공. 기존 하단 버튼과 선택 수·활성 상태·등록 동작 공유.
- 알라딘 API 응답의 설명만 HTML 엔티티를 한 번 복원. 수동 입력·Excel 복원·기존 저장 설명은 조회와 재저장 시 원문 유지.
- 수동 입력 원문, 정보 보강, 반복 Excel 복원, 알라딘 단일·일괄 등록 및 이중 인코딩 회귀 검증 추가.
- package/lockfile 및 로컬·발행용 Compose의 버전 3.1.0 반영.

## 기존 3.0.0 설치 업데이트

기존 `.env`와 실제 데이터 볼륨 이름을 유지하고 웹·워커를 같은 버전으로 함께 교체합니다.

```sh
BOOKSHELF_IMAGE=trstyq/bookshelf:3.1.0 docker compose -f docker-compose.release.yml pull
BOOKSHELF_IMAGE=trstyq/bookshelf:3.1.0 docker compose -f docker-compose.release.yml up -d
```

새 DB 마이그레이션 없이 기존 DB 버전 4를 사용합니다. 출처를 구별할 수 없는 기존 저장 설명은 일괄 변환하지 않습니다. 이미 입력한 설명은 그대로 보존하며, 이후 알라딘 등록·정보 보강으로 받은 설명에 변환을 적용합니다.

Java 데이터 이전이 필요하면 [이전·전환 절차](ONE_CLICK_MIGRATION.md)의 ca2 이전용 이미지로 먼저 이전합니다. 기존 ca2 이미지 태그와 볼륨 연결 위치는 해당 안내를 따릅니다.
