# Bookshelf 3.5.0

완료 알림·책 상세 편집·표지 확대 개선과 알라딘 등록 순서 수정.

## 변경 내용

- 검색·등록·수정 완료 알림의 토스트 전환. 자동 닫힘·직접 닫기와 반복 작업 알림 지원, 새로고침 시 이전 완료 메시지 재표시 방지.
- 책 상세의 메인 수정 폼을 **책 정보 수정** 버튼으로 여는 모달로 이동. 요약 영역에 저자 표시, 저장 실패 시 입력 유지와 성공 시 모달 닫기·토스트 표시.
- 책 상세와 권 편집의 표지 URL 입력 제거. 표지 파일 업로드와 기존 표지 유지.
- Java 표지 확대 동작 복원. PC 호버 즉시 표시, 터치 450ms 누르기, 화면 범위 안에서 원본 비율 유지. 손 떼기·이동·스크롤·취소·Escape 시 닫기와 짧은 탭의 기존 링크 이동 유지.
- 기존 책에 알라딘 결과 추가 시 직접 체크 순서로 권 번호 부여. 해제 후 다시 체크하면 선택 순서의 마지막에 배치. 일괄 선택은 출간일 오름차순, 같은 출간일은 검색 결과 페이지·표시 순서 적용. 미리보기와 실제 저장 순서 일치, 외전의 정규 권차 제외.
- 책 저장 시 세션 만료·폐기를 `UNAUTHORIZED`로 전달. 실패한 모달의 입력 유지와 재로그인 후 저장 재시도 지원.
- 외곽선 버튼 호버의 글자 대비 보정.
- DB 스키마 6에 계정별 메타데이터 보강 작업 저장 추가. 기존 책·권·표지·재고·권한의 마이그레이션 중 변경 없음.

## 기존 설치 업데이트

정식 태그명은 `v3.5.0`입니다. 해당 GitHub Release와 Docker 이미지 발행을 확인한 뒤 기존 `.env`와 데이터 볼륨을 유지하여 웹·워커를 함께 교체합니다.

```sh
BOOKSHELF_IMAGE=trstyq/bookshelf:3.5.0 docker compose -f docker-compose.release.yml pull
BOOKSHELF_IMAGE=trstyq/bookshelf:3.5.0 docker compose -f docker-compose.release.yml up -d
```

DB당 워커 하나를 사용합니다. 스키마 변경 전 자동 백업 설정을 유지하며, Java 데이터 이전이 필요한 경우 [이전·전환 절차](ONE_CLICK_MIGRATION.md)를 먼저 확인합니다.


## RC에서 정식 버전으로 전환

PR #60으로 canary에 병합된 `v3.5.0-rc.1`의 기능·인증 수정 사항을 포함합니다. RC에서 제공한 프로필의 **전체 책 저자·설명 채우기** 버튼과 진행 섹션은 다음 릴리즈로 연기하여 이번 정식 버전에서 제외합니다. 기존 책 상세의 개별 정보 보강은 유지합니다. 패키지·lockfile·Compose·업데이트 문서의 버전을 `3.5.0`으로 맞춥니다.

3.4.0의 DB 스키마 5는 버전 6으로 전환합니다. 이미 RC에서 전환한 DB는 스키마 6을 유지합니다. 웹·워커에는 같은 버전과 데이터 경로를 사용합니다.

## 검증

RC 발행 커밋에서 소스 테스트 334개, 프로덕션 빌드, PC·모바일 E2E 249개와 회원가입 E2E 2개를 검증했습니다. 데스크톱 전용 넓은 화면 검사의 모바일 항목 1개는 설계상 제외했습니다.

정식 버전에서도 `npm run verify:source`, `npm run build`, 전체 E2E와 회원가입 E2E를 다시 실행합니다. GitHub Release의 `verification.json`·`release-evidence.json`에는 발행 소스 커밋, 최종 검사 결과와 Docker 소스 일치·공유 데이터·기존 데이터 정리 검증을 기록합니다.

브라우저·Docker 검사는 임시 DB·계정·볼륨과 알라딘 fixture를 사용합니다. 이미지 발행과 운영 서비스 교체는 별도 단계입니다.
