# Bookshelf 3.5.0-rc.1

완료 알림·책 상세 편집·표지 확대 개선과 알라딘 등록 순서 수정, 전체 책 정보 보강 추가.

## 변경 내용

- 검색·등록·수정 완료 알림의 토스트 전환. 자동 닫힘·직접 닫기와 반복 작업 알림 지원, 새로고침 시 이전 완료 메시지 재표시 방지.
- 책 상세의 메인 수정 폼을 **책 정보 수정** 버튼으로 여는 모달로 이동. 요약 영역에 저자 표시, 저장 실패 시 입력 유지와 성공 시 모달 닫기·토스트 표시.
- 책 상세와 권 편집의 표지 URL 입력 제거. 표지 파일 업로드와 기존 표지 유지.
- Java 표지 확대 동작 복원. PC 호버 즉시 표시, 터치 450ms 누르기, 화면 범위 안에서 원본 비율 유지. 손 떼기·이동·스크롤·취소·Escape 시 닫기와 짧은 탭의 기존 링크 이동 유지.
- 기존 책에 알라딘 결과 추가 시 직접 체크 순서로 권 번호 부여. 해제 후 다시 체크하면 선택 순서의 마지막에 배치. 일괄 선택은 출간일 오름차순, 같은 출간일은 검색 결과 페이지·표시 순서 적용. 미리보기와 실제 저장 순서 일치, 외전의 정규 권차 제외.
- 프로필에 **전체 책 저자·설명 채우기** 추가. 현재 계정의 전체 책·권에서 빈 저자·설명만 알라딘 API로 보강하고 기존 입력값 보존. 워커의 책 단위 처리와 진행·보강·변경 없음·실패 집계, 페이지 이탈 및 워커 재시작 후 진행 재개 지원.
- DB 스키마 6에 계정별 메타데이터 보강 작업 저장 추가. 기존 책·권·표지·재고·권한의 마이그레이션 중 변경 없음.

## 기존 설치 업데이트

RC 태그명은 `v3.5.0-rc.1`입니다. 해당 GitHub Release와 Docker 이미지 발행을 확인한 뒤 기존 `.env`와 데이터 볼륨을 유지하여 웹·워커를 함께 교체합니다.

```sh
BOOKSHELF_IMAGE=trstyq/bookshelf:3.5.0-rc.1 docker compose -f docker-compose.release.yml pull
BOOKSHELF_IMAGE=trstyq/bookshelf:3.5.0-rc.1 docker compose -f docker-compose.release.yml up -d
```

DB당 워커 하나를 사용합니다. 스키마 변경 전 자동 백업 설정을 유지하며, Java 데이터 이전이 필요한 경우 [이전·전환 절차](ONE_CLICK_MIGRATION.md)를 먼저 확인합니다.

## 준비 상태

`canary` 병합 PR용 RC 릴리즈 준비입니다. 버전·lockfile·Compose·문서 정합성과 로컬 소스·브라우저 검증을 포함합니다. RC 태그·GitHub Release·Docker 이미지의 발행 및 운영 서비스 교체는 이후 별도 단계입니다.

## 검증

- `npm run verify:source`: 구문·구조·타입 검사 및 28개 파일의 단위·통합 테스트 329개 통과.
- `npm run build`: Next.js 프로덕션 빌드 통과.
- PC·모바일 전체 E2E 246개 범위 검증: 237개 통과 후 모달 진입 경로를 보완한 8개 재검증 통과, 데스크톱 전용 레이아웃의 모바일 1개 설계상 제외. 최종 범위 245개 통과.
- 회원가입 별도 E2E 2개 및 호버 대비 보정 후 책 수정·전체 정보 보강 UI E2E 4개 추가 통과.
- DB 스키마 1~5의 버전 6 전환, 계정 범위·기존 입력 보존·보강 진행 재개·개별 조회 실패 후 계속 처리 검증 포함.

브라우저 검사는 Chromium의 PC·모바일 환경과 임시 DB·워커·알라딘 fixture를 사용합니다. 원격 발행·운영 배포 검증과 구분합니다.
