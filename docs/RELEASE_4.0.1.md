# Bookshelf 4.0.1

알라딘 검색에서 기존 소장 도서의 체크박스가 활성화되던 문제 수정. 4.0.0의 공개 HTML 연동과 ISBN 중복 등록 검사를 유지한 패치.

- 기존 OpenAPI 구매 링크의 부가 파라미터·프로토콜 차이와 무관하게 알라딘 상품 번호로 소장 여부 판별
- ISBN10·ISBN13 및 하이픈·대소문자 차이를 정규화해 동일 도서 판별
- ISBN 대신 K/U 코드만 있는 검색 결과는 필요한 상품 상세를 조회해 ISBN만 저장된 소장 권도 확인
- 소장 권 체크박스 비활성화 및 일괄 선택 제외, 초기 검색·페이지 이동·한 권 추가에 공통 판별 적용
- 다른 계정의 소장 도서는 선택 가능하도록 계정별 분리 유지
- README의 미출시·검토 중 표현 제거 및 정식 버전 실행·업데이트·운영 안내 정리

DB 스키마 변경 없음(버전 7 유지). 기존 `.env`·DB·표지·백업과 데이터 볼륨을 유지하고 웹·워커를 함께 `trstyq/bookshelf:4.0.1`로 교체. `latest`도 동일 이미지로 발행. 업데이트 명령은 [README](../README.md#docker), Java 이전 안내는 [이전·전환 문서](ONE_CLICK_MIGRATION.md) 참고.

ISBN 확인이 필요한 결과는 상세 조회가 추가되어 첫 검색 시간이 늘 수 있음. 조회에 실패하면 확인되지 않은 선택 결과를 반환하지 않고 오류 표시. 실제 알라딘 응답에 대한 대규모 부하 시험은 미수행.

최종 main 소스·Docker 이미지·테스트·발행 검증 결과는 [GitHub Release](https://github.com/ts2580/library/releases/tag/v4.0.1)의 부속 증적 참고. 이미지 발행과 기존 운영 서비스의 컨테이너 교체는 별도 상태로 보고.
