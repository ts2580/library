# Bookshelf 3.3.2

재고 갱신 실패 원인 로그와 개별·선택·실패 전체 재시도 추가.

## 변경 내용

- 지점 재고의 **갱신 로그**에서 권 제목·ISBN·조회 시각·결과·실패 코드와 이유 확인. 미해결 실패와 전체 이력 필터 및 페이지 선택 제공.
- 로그의 **개별 갱신**, **선택 갱신**, **실패 건 재시도** 지원. 지점 재고 페이지는 실패가 있을 때만 전체 삭제와 갱신 시작 사이에 실패 건 재시도 버튼 표시.
- 재시도는 현재 계정의 구매 필요 권만 처리. 성공한 권의 재고만 교체하며, 재고 없음 확인 시 해당 권의 이전 재고 삭제. 실패하거나 상세를 확인하지 못한 권의 이전 재고와 선택하지 않은 권의 재고 유지.
- 성공·재고 없음으로 처리한 권은 미해결 실패 건수에서 제외하고 이전 실패 기록은 전체 이력에 보존. 구매 완료·구매 불필요 권은 재시도 대상에서 제외.
- 작업 취소·새 작업 전환 시 이전 워커의 재고 및 로그 저장 차단. 권한·요청 실패·시간 초과는 오류 팝업으로 표시.

## 기존 설치 업데이트

`3.3.2` 이미지 발행을 확인한 뒤 기존 `.env`와 데이터 볼륨을 유지하여 웹·워커를 함께 교체합니다.

```sh
BOOKSHELF_IMAGE=trstyq/bookshelf:3.3.2 docker compose -f docker-compose.release.yml pull
BOOKSHELF_IMAGE=trstyq/bookshelf:3.3.2 docker compose -f docker-compose.release.yml up -d
```

DB 스키마 버전 5에서 갱신 이력·선택 대상 테이블을 추가하며 기존 책·표지·재고는 유지합니다. 기본 설정에서는 마이그레이션 전 DB 백업을 자동 생성합니다. 웹·워커에 같은 버전과 DB 경로를 사용해야 합니다.

상세 로그는 업데이트 후 실행한 작업부터 저장합니다. 이전 버전의 실패 합계만으로 개별 실패 이유를 복원하지 않습니다. 로그의 시각은 UTC로 표시합니다.

기존 **갱신 시작**은 워커가 시작할 때 현재 계정의 전체 재고를 지우고 다시 조회합니다. **실패 건 재시도**와 로그의 갱신 버튼은 선택한 권만 처리합니다.
