# Bookshelf 3.4.0

책 상세의 저장·목록 복귀와 재고 탐색 개선.

## 변경 내용

- 권 정보 모달에서 첫 저장과 반복 저장 시 페이지 스크롤 유지 및 저장 성공 후 모달 닫기. 저장 실패 시 입력값과 모달 유지, 오류 안내 제공.
- 책 상세의 브라우저 탭에 실제 책 제목 표시. 로그인 계정이 소유한 책만 제목 조회.
- 책장·보유 권 검색·지점 재고·갱신 로그·알라딘 검색에서 상세 진입 후 이전 목록 및 검색 조건·페이지 복원. 책 수정·권 추가·권 삭제·정보 보강 후에도 복귀 경로 유지.
- 보유 권 검색의 알라딘 한 권 등록 후 상세에서 책을 삭제해도 현재 알라딘 검색어·페이지와 보유 권 필터 복원. 검색 조건이 주소창에 없거나 이전 검색 조건이 남아 있어도 화면의 검색 결과 기준으로 복원.
- 복귀 경로를 앱 내부의 허용된 목록으로 검증하고 이전 안내·오류 파라미터 제거. 마지막 책을 삭제한 지점은 기존 검색 조건을 유지하여 재고 목록으로 복귀.
- 재고 구매 URL의 알라딘 상대 경로 보정 및 상품 구매 링크가 없을 때 기존 목록 링크 사용. 유효한 링크가 없으면 **구매 링크 없음** 표시.
- 지점·직배송 재고를 책 제목과 숫자 권차 기준으로 정렬하며 페이지 이동 시 순서 유지.
- 확인한 재고 갱신·표지 복원 작업의 오류 팝업을 같은 브라우저 탭에서 화면 이동·새로고침 후 반복 표시하지 않도록 수정. 새로운 작업의 오류는 별도 표시.

## 기존 설치 업데이트

`3.4.0` 이미지 발행을 확인한 뒤 기존 `.env`와 데이터 볼륨을 유지하여 웹·워커를 함께 교체합니다.

```sh
BOOKSHELF_IMAGE=trstyq/bookshelf:3.4.0 docker compose -f docker-compose.release.yml pull
BOOKSHELF_IMAGE=trstyq/bookshelf:3.4.0 docker compose -f docker-compose.release.yml up -d
```

3.3.2에서 DB 스키마 버전 5를 유지하며 추가 스키마 변경은 없습니다. 기존 책·권·표지·재고와 백업을 유지합니다. 더 오래된 버전에서 업데이트하면 기존 조건부 마이그레이션을 적용하며, 기본 설정에서는 마이그레이션 전 DB 백업을 자동 생성합니다.

웹·워커에는 같은 버전과 DB 경로를 사용해야 합니다. 워커는 DB당 하나만 실행합니다. Java 데이터 이전이 필요하면 [이전·전환 절차](ONE_CLICK_MIGRATION.md)를 먼저 확인합니다.
