# Bookshelf 3.5.1

동일 출간일의 알라딘 일괄 추가 권차 수정과 프로필의 임시 표지 재생성 메뉴 제거.

## 변경 내용

- 일괄 선택 시 출간일 오름차순을 먼저 적용하고, 같은 출간일은 제목의 숫자를 비교하여 권차 부여. `츠구모모 33·32·31` 순서로 검색돼도 기존 30권 다음에는 `31→31권, 32→32권, 33→33권`으로 미리보기와 실제 저장 일치.
- 제목의 숫자를 문자열 순서로 비교하지 않고 `2→10`, `31→32→33` 순서로 처리. 출간일 미상은 마지막에 배치.
- 직접 체크한 순서와 해제 후 재선택, 외전의 정규 권차 제외 유지.
- 프로필의 **표지 재생성** 섹션·버튼과 실행 액션 제거. 알라딘 등록의 자동 표지 다운로드 및 책·권 편집의 표지 파일 업로드 유지.
- 표지 다운로드 실패 시 책 상세의 파일 업로드로 안내 변경.
- 전체 책 저자·설명 채우기는 이전 데이터 누락 보정용 CA 임시 도구로 구분. 정식 메뉴 및 다음 마이너 버전의 추가 기능 계획에서 제외.

## 기존 설치 업데이트

`v3.5.1` GitHub Release와 `trstyq/bookshelf:3.5.1` 이미지 발행을 확인한 뒤 기존 `.env`와 데이터 볼륨을 유지하여 웹·워커를 함께 교체합니다.

```sh
BOOKSHELF_IMAGE=trstyq/bookshelf:3.5.1 docker compose -f docker-compose.release.yml pull
BOOKSHELF_IMAGE=trstyq/bookshelf:3.5.1 docker compose -f docker-compose.release.yml up -d
```

3.5.0의 DB 스키마 6을 유지하며 추가 스키마 변경은 없습니다. 기존 책·권·표지·재고와 백업은 유지합니다. 더 오래된 버전에서는 기존 조건부 마이그레이션과 기본 자동 백업을 적용합니다. DB당 워커 하나를 사용합니다.

3.5.0에서 이미 잘못 저장한 권차를 자동으로 바꾸지는 않습니다. 영향을 받은 권은 책 상세에서 직접 수정합니다. 이번 수정은 이후 알라딘 선택 등록부터 적용합니다.

Java 데이터 이전이 필요하면 [이전·전환 절차](ONE_CLICK_MIGRATION.md)를 먼저 확인합니다.

## 검증

기능 수정 커밋에서 소스 테스트 338개, 프로덕션 빌드 및 PC·모바일 E2E 54개를 검증했습니다. 정식 버전에서도 소스·빌드·전체 E2E·회원가입 및 Docker 검증을 다시 수행하고 최종 결과는 GitHub Release의 `verification.json`·`release-evidence.json`에 기록합니다.

브라우저·Docker 검사는 임시 DB·계정·볼륨과 알라딘 fixture를 사용합니다. 이미지 발행과 운영 서비스 교체는 별도 단계입니다.
