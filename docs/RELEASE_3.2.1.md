# Bookshelf 3.2.1

중고 재고 갱신 상태 복구 및 공통 오류 코드 팝업 추가.

## 변경 내용

- 실제 재고 갱신이 끝나도 상태 조회 응답이 멈추면 `QUEUED`와 상단 진행 막대가 남는 문제 수정. 상태 조회에 10초 제한 및 자동 재시도 적용.
- 탭 복귀와 새 서버 데이터 수신 시 진행 상태 재조회, 완료 후 재고 결과 갱신 및 진행 표시 해제.
- 로그인·접근 권한 오류 시 상태 조회 중단 및 안내 표시. 조회 오류와 실제 워커 실패를 구분하고 이전 조회 응답이 새 작업을 덮어쓰지 않도록 보호.
- API·폼 처리·작업 실패의 오류 코드, 메시지 및 상세를 공통 팝업으로 표시. 상세 복사, 확인·Esc 닫기, 키보드 포커스 및 기존 모달 입력 유지 지원.
- 반복 조회 오류의 팝업 중복 표시 억제 및 정상 응답 복구 시 자동 해제.

## 기존 설치 업데이트

`3.2.1` 이미지 발행을 확인한 뒤 기존 `.env`와 실제 데이터 볼륨 이름을 유지하여 웹·워커를 함께 교체합니다.

```sh
BOOKSHELF_IMAGE=trstyq/bookshelf:3.2.1 docker compose -f docker-compose.release.yml pull
BOOKSHELF_IMAGE=trstyq/bookshelf:3.2.1 docker compose -f docker-compose.release.yml up -d
```

DB 스키마 버전 4를 유지하며 새 마이그레이션은 없습니다. DB·표지·업로드·백업은 기존 볼륨을 그대로 사용합니다.

일괄 재고 갱신은 워커가 실제 작업을 시작할 때 현재 계정의 이전 재고를 전부 삭제하고 새 결과를 저장합니다. 대기 중에는 기존 재고를 유지하며 다른 계정 재고는 삭제하지 않습니다.
