# Bookshelf 4.1.0 준비 기록

## 소스 범위

- 기준 main: `5ac0d3bc54cf374d5057aae33acdd6099d551df2` (정식 4.0.1)
- canary: `ff221bbff974dc7fbf319b960863e653e5bf6c67` (PR #70 병합)
- `release/4.1.0`에서 main과 canary 통합. main의 ISBN 중복 검사 보완 및 기존 릴리즈 수정 보존.
- 로컬 npm 배포 준비 파일과 기타 미커밋 변경은 포함하지 않음.

## 검증

- `npm run verify:source`: 구문·구조·타입 검사 및 35개 파일/415개 테스트 통과.
- `npm run build`: Next.js 프로덕션 빌드 통과.
- `linux/amd64` 로컬 Docker 이미지 `bookshelf:4.1.0-local` 빌드 통과.
- 이미지 ID: `sha256:4f5b8d8ecd7e791fb6d7706539e77b483c6084062869f0571d1ff4334b89f481`.
- 애플리케이션·워커·설정·스크립트 등 런타임 파일 179개 SHA-256 대조 일치.
- Docker 스모크: 웹·워커 기동, UID 1001, 공유 데이터 볼륨, 익명 API 차단, DB 무결성 검사 통과.
- Docker Java 원본 정리: 권한 복구·인증된 관리자 정리 API·활성 DB·표지·백업 보존 검증 통과.
- 프로덕션 빌드 기반 전체 PC/모바일 E2E: 259개 통과, 데스크톱 전용 넓은 화면 검사의 모바일 항목 1개 의도적 제외(13.1분).
- 별도 회원가입 E2E: PC/모바일 2개 통과.

검증 로그·로컬 후보 산출물·체크섬은 이 작업 공간의 `temp/release-4.1.0/`에 보관. 전체 E2E 결과는 `e2e-full-results/`에 별도 보존. 후보 소스 압축본은 검증 기록을 포함한 릴리즈 브랜치 커밋으로 생성하며, 최종 main 병합 후 정식 산출물은 해당 main 커밋 기준으로 생성·검증 필요. 이 이미지는 릴리즈 준비 검증용이며 원격 이미지 발행 증거가 아님.

애플리케이션 소스와 설정은 위 검증 이후 변경하지 않았으며, 후속 커밋은 이 검증 기록만 갱신.
